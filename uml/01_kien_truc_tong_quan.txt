nginx --> webapp : reverse proxy
nginx --> parser : access.log (tail)

parser --> events : append JSONL events
collector --> events : read stream
collector --> scoring : POST /score
scoring --> model : load + infer
scoring --> collector : stage/confidence/decision
collector --> alertsdb : persist ALERT
collector --> n8nwebhook : POST alert payload
n8nwebhook --> telegram : notify
